# Thanks

Ideas Quarterdeck borrowed, and where they came from.

- **Memory curation** ("dreaming", issue #42): the idea that an agent's memory should be tidied over time instead of only growing, with stale memories fading, comes in part from [beads](https://github.com/gastownhall/beads) and its memory decay. The index-and-recall pattern follows the Memory section of Anthropic's [Building always-on agents](https://claude.com/resources/articles/building-always-on-agents).
