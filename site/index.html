What it is

Quarterdeck is a Claude Code plugin that turns Claude into a personal assistant. It keeps looking after the things you hand it, asks before it does anything you haven't allowed, and remembers what you decided.

You give it goals: "sell my birdcage", "fix new issues on my repo", "find me the three best new job ads each week", "clear old installers out of Downloads". Each goal runs on its own schedule in the background of your Claude Code session, on your Claude plan. When it wants to act, it proposes, and you approve or reject from the Goals pane beside your chat, or from your phone.

What it's like to use

It asks first

A buyer offers $30 for your $50 birdcage. The reply countering at $40 waits under Needs you until you approve it, and nothing goes to the buyer before that. Reject a draft as "too formal" and that feedback becomes memory that later runs follow.

It asks when it's stuck

When a run needs something only you can give, like your lowest price or when buyers can pick up, it asks you instead of guessing, then carries on with your answer.

It reaches you when you're away

With Remote Control connected, a new proposal or question shows up in the Claude app on your phone. Reply "approve" and it's done.

It earns trust one kind of action at a time

Each kind of action (message a buyer, buy, delete a file) is set to off, propose or auto. After 10 approvals in a row, the pane offers to switch that kind to auto.

It remembers

Each goal keeps its own memory, its open items and its run history outside any one conversation, so it never assesses the same listing twice.

You see what it costs

Each run shows the tokens and time it used, for example 48k tokens · 2m.

Selling a birdcage

It started with one prompt: /goal-new Sell my as-new (unused) birdcage on Facebook Marketplace. I live in Tawa, Wellington. The photos are the two newest pictures in my Pictures folder. Price $50, pick-up only.

  1. The first run found the two photos, wrote the listing (dimensions in centimetres, category, condition) and proposed posting it. Nothing went up until I approved it.
  2. The next run filled in Facebook's form through Claude in Chrome, published the listing and turned down Facebook's offer to boost it for a fee.
  3. It asked me once for my lowest price and when buyers could pick up, then checked the Marketplace inbox every few hours. Five people got in touch. For each one it drafted a reply and waited for my OK. One offered $30, and it proposed countering at $40 instead of dropping straight to my floor.
  4. The next morning two buyers wanted it, one that afternoon and one on Saturday. It laid out both, suggested the sooner one with Saturday as a backup, and let me choose. It sent my address only after I gave it the address to send.
  5. Once I confirmed the buyer had collected it and paid, it marked the listing sold and sent the other four a short note.

My part was approving each reply, choosing the buyer and giving the address. The agent never messaged anyone on its own.

A goal that never finishes

Selling one thing is a one-off goal, and it moves to Done once nothing is left open. Flipper is the standing kind: grow a NZ$200 budget by buying underpriced things on Facebook Marketplace and Trade Me and reselling them at a profit.

Watches on new listings start a run when something new appears. Each run sorts the new titles by name and price, opens at most five, looks at every photo, and skips anything that needs a repair, like a freezer whose lid doesn't seal. A deal worth proposing comes with comparable sales, a resale estimate, the fuel for the round trip, the expected profit, a suggested offer and a pick-up time that fits my week. A ledger in its memory tracks the capital, the stock and each flip.

Its first buy was a dryer for NZ$80 on Trade Me that should resell for NZ$150 to 180.

From issue to merged pull request

Quarterdeck's own repo is looked after by Quarterdeck goals. They have no schedule. Each has a watch, a gh command checked every 5 minutes, and a run starts only when the watch sees something new.

For issue #1, the Issue Fixer's watch saw the new issue within 5 minutes. The run read the issue as untrusted text, fixed it on a branch in its own clone, added tests and ran them, then proposed opening a pull request. Nothing was pushed until I approved. The next run opened PR #2, CI passed on all five checks, and I merged it. The run took 2 minutes.

A longer chain sorts and specifies issues before any code gets written:

new issue → Issue Triage → triaged → (you pick) → needs-refinement
          → Issue Refiner → refined → Issue Fixer → pull request

An issue anyone can open is an obvious place to hide instructions for an agent. So the Issue Fixer only takes work from the repo's owner, members and collaborators, and asks you before reading an issue from anyone else. Pushing and opening a pull request wait for your approval in Quarterdeck's guard, outside the model, as well as in the goal's instructions.

How it differs

From Claude Code's scheduled tasks

Scheduled tasks (/schedule) run in Anthropic's cloud, so they keep going with your laptop closed. They suit clear-cut work, like reviewing every PR. A Quarterdeck goal is for ongoing jobs where you want a say: it proposes and waits for you, keeps memory and items between runs, and asks when it's unsure. Its guard holds a run to what you've allowed outside the model, rather than only asking in the prompt.

From OpenClaw

OpenClaw is a self-hosted, always-on assistant you message from WhatsApp, Telegram and other chat apps. Quarterdeck is much smaller, with no gateway or server to run. A goal's run is a Claude Code subagent, so it can use the skills, plugins, MCP servers and connectors you already have in Claude Code, on your Claude plan.

Limits

  • It runs on your computer. Goals run while a Claude Code window is open, or with none open once you set up the standing session. Either way the computer has to be on and you logged in.
  • Phone alerts need Remote Control connected and mobile push turned on in /config.
  • It's early. One person builds it and uses it daily, on Windows, so expect rough edges.

Install

You need Claude Code and Node.js 22.13 or newer. From a terminal:

claude plugin marketplace add shannonbay/Quarterdeck#release
claude plugin install quarterdeck-goals@quarterdeck --scope user

That's the whole setup. The guard plugin and the MCP server come with it. Start Claude Code, type /goal-new, and /goals opens the Goals pane.

To get new versions automatically: /plugin → Marketplaces → quarterdeck → Enable auto-update.

More in the README: the standing session for running goals with Claude Code closed, the optional web app, the guard, and every MCP tool.
